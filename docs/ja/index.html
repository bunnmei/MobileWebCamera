English

スマホのカメラを、
PC の Web カメラに。

Android 端末のカメラ映像を、USB テザリングや Wi-Fi で PC へ配信します。
受信は OBS の「メディアソース」だけ。PC に追加のソフトは要りません。

使い方を見る GitHub

特徴

PC 側はインストール不要

OBS や VLC で受信できます。Windows・macOS・Linux のどれでも使えます。

低遅延の H.264 配信

端末のハードウェアで H.264 に変換し、MPEG-TS で送ります。

本格的なカメラ設定

レンズ切替、マニュアルフォーカス、ISO・シャッタースピード、ホワイトバランスなど。

データは外に出ない

映像はつないだ PC へ直接届くだけ。アカウント登録も、広告も、解析ツールもありません。

必要なもの

  • Android 9 以降のスマートフォン（カメラ付き）
  • OBS Studio などの受信ソフトが入った PC
  • スマホと PC をつなぐ USB ケーブル、または同じ Wi-Fi
