使い方

MobileWebCamera ／ Android 9 以降

3 ステップで使えます。スマホと PC を USB か Wi-Fi でつなぐ → アプリで「配信開始」 → OBS の「メディアソース」に表示された URL を入れる。

1. スマホと PC をつなぐ

次のどちらかの方法で、スマホと PC を同じネットワークにつなぎます。

USB でつなぐ（おすすめ）

映像が途切れにくく、遅延も少ない方法です。adb などの開発者向けツールは要りません。

  1. USB ケーブルでスマホと PC をつなぐ充電専用ではなく、データ通信ができるケーブルを使ってください。
  2. USB テザリングをオンにするスマホの「設定」→「ネットワークとインターネット」→「テザリング」→「USB テザリング」をオンにします。メニューの名前は機種によって少し違います。

Wi-Fi でつなぐ

スマホと PC を同じ Wi-Fi（同じルーター）に接続します。ケーブルが要らない代わりに、電波の状態によっては映像が乱れることがあります。

モバイルデータ通信（4G / 5G）では使えません

PC から届く USB テザリングと Wi-Fi のアドレスだけをアプリに表示しています。

2. 配信を始める

  1. アプリを開いて、カメラへのアクセスを許可する
  2. 「配信」タブで「配信開始」を押すAndroid 17 以降では「ローカルネットワークへのアクセス」の許可を求められます。PC からつなぐのに必要なので、許可してください。
  3. 表示された URL を確認するtcp://192.168.42.129:4747 のような URL が、USB または Wi-Fi のラベル付きで表示されます。この URL を次の手順で使います。

配信中はアプリを閉じても（バックグラウンドにしても）配信が続きます。通知欄に「配信中」と出ている間は配信が続いています。止めるときはアプリに戻って「配信停止」を押してください。

3. OBS で受信する

  1. OBS の「ソース」で「＋」→「メディアソース」を選ぶ
  2. 次のように設定して「OK」を押す
項目設定する値
ローカルファイルオフ
入力アプリに表示された URL（例：tcp://192.168.42.129:4747）
入力フォーマットmpegts
ネットワークバッファリング0 MB
FFmpeg のオプションanalyzeduration=500000
可能な場合ハードウェアデコードを使用オン

FFmpeg のオプションは入れなくても映りますが、入れると映るまでの待ち時間が約 5 秒から約 1.5 秒に短くなります。

Zoom や Teams などで使うには

OBS の「仮想カメラ開始」を押すと、OBS の画面を Web カメラとして他のアプリで選べるようになります。

4. OBS 以外で受信する

URL の tcp:// を http:// に変えても受信できます。VLC なら「メディア」→「ネットワークストリームを開く」に次のように入れます。

http://192.168.42.129:4747/

IP アドレスの部分は、アプリに表示されたものに置き換えてください。

5. 各タブの説明

画面右上のメニューから設定を開けます。選択肢はその端末のカメラが対応しているものだけが表示されるので、機種によって出てくる項目が違います。

レンズカメラの切り替え（超広角・望遠などの個別レンズも含む）、ズーム、ライト（トーチ）とその明るさ

映像の向き

最初は「自動」で、スマホの持ち方に合わせて映像がまっすぐになります。スマホを机に寝かせても、最後の向きのままになります。スタンドに固定するときなどは、向きを決めておくと安定します。

  • 縦：縦長の映像（例：1080×1920）で配信
  • 横（右が上）・横（左が上）：画面を自分に向けたとき、スマホの右端・左端が上になる持ち方

「マルチ」と「物理」のレンズ

マルチはズーム倍率に合わせて自動でレンズを切り替えるカメラです。物理は 1 つのレンズを直接使います。物理レンズ単体で映せない機種では、自動でマルチに切り替わります。その場合はズーム倍率でレンズを選んでください。

6. 困ったときは

OBS に何も映らない・つながらない
  • アプリで「配信開始」を押しているか確認してください。
  • スマホと PC が同じネットワーク（USB テザリング、または同じ Wi-Fi）につながっているか確認してください。
  • OBS の「入力」が、アプリに今表示されている URL と同じか確認してください。USB をつなぎ直すと IP アドレスが変わることがあります。
  • Android 17 以降では「ローカルネットワークへのアクセス」を許可してください。拒否した場合は「設定」→「アプリ」→「MobileWebCamera」→「権限」から変えられます。
  • PC のファイアウォールや、会社・学校・公共の Wi-Fi の設定で通信が止められていることがあります。その場合は USB でつないでください。
映るまでに時間がかかる・遅延が大きい
  • OBS の「ネットワークバッファリング」を 0 MB にしてください。
  • 「FFmpeg のオプション」に analyzeduration=500000 を入れてください。
  • Wi-Fi よりも USB の方が遅延は少なくなります。
映像が乱れる・ブロック状のノイズが出る
  • 「配信」タブの「キーフレーム要求」を押すと、きれいな画面から送り直します。
  • ビットレートや解像度を下げると安定します。
  • Wi-Fi の場合は、ルーターに近づくか USB に切り替えてください。
映像が横向き・逆さまになる

「配信」タブの「映像の向き」で、スマホの持ち方に合った向きを選んでください。

「カメラを開けません」「カメラが切断されました」と出る

ほかのアプリがカメラを使っている可能性があります。カメラを使うほかのアプリを閉じてから、もう一度試してください。

スマホが熱くなる・電池の減りが早い

長時間の配信では端末が熱くなりやすくなります。解像度やフレームレートを下げる、スマホケースを外す、USB でつないで充電しながら使う、などを試してください。

解決しないときは GitHub の Issues で教えてください。
